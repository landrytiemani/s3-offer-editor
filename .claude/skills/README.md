# Cybersecurity Skills

This directory contains the [Anthropic-Cybersecurity-Skills](https://github.com/mukul975/Anthropic-Cybersecurity-Skills)
library — 817 community-authored, agentskills.io-standard cybersecurity skills — installed as
project-scoped Claude Code skills.

Each subdirectory is a self-contained skill with a `SKILL.md` (YAML frontmatter + workflow) and,
where applicable, `references/`, `scripts/`, and translated variants. Claude Code discovers them
automatically from `.claude/skills/`.

- Source: https://github.com/mukul975/Anthropic-Cybersecurity-Skills
- Author: mukul975 (mahipal)

- Version installed: 1.3.0

> dual-use techniques intended for **authorized** penetration testing, security research, defense,
> and education only. Use solely against systems you own or have explicit written permission to test.
